Esteganografia

Esconda um texto dentro de uma imagem ou descubra o que uma imagem guarda.

O que é e como funciona

Cada pixel de uma imagem guarda três números: vermelho, verde e azul. O programa troca o último bit de cada um por um bit da mensagem. A mudança é pequena demais para o olho notar.

Para ler, o caminho é o inverso: os últimos bits são reunidos até formar o texto.

  1. Escolha uma imagem.
  2. Escreva a mensagem e clique em Esconder.
  3. Baixe o PNG gerado.

Para revelar, envie o PNG gerado e clique em Revelar. Não converta para JPG: a compressão apaga a mensagem.
